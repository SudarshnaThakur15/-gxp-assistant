# SPEC-ALD-001 Drug Product Specification: ALD-101 100 mg/mL (v2.0)

## 1. Product
ALD-101, a monoclonal antibody, 100 mg/mL solution for injection in 10 mL Type I glass vials.

## 2. Manufacturing site
NorthBridge CDMO, site NB-1, fill line FL-2.

## 3. Sampling
Samples are taken as defined in the ALD-101 master batch record.

## 4. Release specification
| Test | Acceptance criterion |
|---|---|
| Appearance | Clear to slightly opalescent, colourless to pale yellow; essentially free of visible particles |
| pH | 5.8 – 6.4 |
| Protein concentration | 95 – 105 mg/mL |
| Purity (SEC-HPLC, monomer) | ≥ 97.0 % |
| Bacterial endotoxins | ≤ 0.5 EU/mg |
| Sterility | No growth |
| Sub-visible particles (≥ 10 µm) | ≤ 6000 per container |
| Sub-visible particles (≥ 25 µm) | ≤ 600 per container |
| Pre-filtration bioburden | ≤ 10 CFU/100 mL |

## 5. Storage and stability
- Store at **2 – 8 °C**, protected from light. Shelf life: **24 months**.
- Time out of refrigeration: up to **24 hours cumulative at ≤ 25 °C** is supported by stability
  data and has no impact on quality.
