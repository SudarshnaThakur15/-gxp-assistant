# SPEC-CRV-001 Drug Product Specification: CRV-220 2 mg/mL PFS (v1.0)

## 1. Product
CRV-220, a synthetic peptide, 2 mg/mL solution in 1 mL glass prefilled syringes with plunger stopper.

## 2. Manufacturing site
NorthBridge CDMO, site NB-1, fill line FL-3.

## 3. Release specification
| Test | Acceptance criterion |
|---|---|
| Appearance | Clear, colourless solution, essentially free of visible particles |
| pH | 4.0 – 5.0 |
| Assay (HPLC) | 95.0 – 105.0 % of label claim |
| Related substances | Total ≤ 3.0 % |
| Bacterial endotoxins | ≤ 5 EU/mL |
| Sterility | No growth |
| Break-loose force | ≤ 10 N |
| Glide force | ≤ 8 N |

## 4. Storage and stability
Store at 2 – 8 °C. Shelf life: 18 months. Time out of refrigeration: up to 72 hours at ≤ 25 °C.
