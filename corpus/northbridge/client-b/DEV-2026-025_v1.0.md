# DEV-2026-025 Visible particles found at 100% visual inspection, batch CRV-26-047

## 1. Summary
| Field | Value |
|---|---|
| Discovered | 2026-07-08 |
| Product / batch | CRV-220 / CRV-26-047 |
| Equipment | Fill line FL-3, visual inspection booth VI-2 |
| Classification (QA) | Major |
| Investigator | Sam Rivera, QA Analyst |
| State | Closed 2026-08-05 |

## 2. Immediate actions
Rejected syringes were segregated; the batch was placed on QA hold.

## 3. Description of event
During 100 % visual inspection, **3 of 4,980 syringes** contained a visible black particle.
The reject rate was above the alert level of 0.05 %.

## 4. Investigation and root cause
FTIR analysis identified the particles as bromobutyl rubber, matching the plunger stopper.
Stoppers from the lot in use showed surface damage from the stoppering station.
**Root cause:** a worn insertion tube on the FL-3 stoppering station abrading stopper edges.

## 5. Impact assessment
The remaining 4,977 syringes passed inspection and an AQL re-inspection. No impact on the
released units.

## 6. CAPA
Replace the insertion tube and add it to the preventive maintenance plan (work order WO-6621).

## 7. Closure
QA approved the investigation on 2026-08-05.
